## Featured projects

### [YouTube Playlist Sync](https://github.com/DagerottDev/Youtube_Obsidian_Sync)
Turn public YouTube playlists into an Obsidian knowledge library, with video metadata, transcripts, playlist indexes, and optional AI summaries. Incremental sync preserves your edits.

[Install in Obsidian](https://obsidian.md/plugins?id=youtube-playlist-sync) · [Explore the source](https://github.com/DagerottDev/Youtube_Obsidian_Sync)

### [Mobile API Studio](https://github.com/DagerottDev/mobile-api-studio)
A local-first API debugger with a browser workspace. Capture and inspect traffic, compose or replay requests, mock responses, simulate network conditions, and compare sessions.

Start with an iOS Simulator or Android Emulator. Available to build from source.

[Explore the source](https://github.com/DagerottDev/mobile-api-studio) · [Usage guide](https://github.com/DagerottDev/mobile-api-studio/blob/main/docs/USAGE.md)
