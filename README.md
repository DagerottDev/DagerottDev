## Featured projects

### [Option Analytics Platform](https://github.com/DagerottDev/AnalyticsPlateform)

A self-hosted workspace for Indian options research: option chains, Greeks, volatility analysis, strategy payoffs, and historical replay. Built with Next.js, TypeScript, Python/FastAPI, and PostgreSQL, with Fyers and Dhan integrations. **MIT-licensed source release (v0.1.1).** Single-account workspace; broker coverage varies. Live broker connectivity, real orders, and production deployment are outside the release checks.

[Source and setup](https://github.com/DagerottDev/AnalyticsPlateform) · [Source release](https://github.com/DagerottDev/AnalyticsPlateform/releases/tag/v0.1.1)

### [OpenMoto](https://github.com/DagerottDev/OpenMoto)

A native iOS motorcycle companion for navigation, fuel, maintenance, expenses, and ride history, with experimental Wi-Fi display projection. **In testing — testers and Swift contributors welcome.** Build from source; physical-device and display compatibility validation are pending. No App Store or TestFlight download.

[Source](https://github.com/DagerottDev/OpenMoto) · [Tester guide](https://github.com/DagerottDev/OpenMoto/blob/main/Docs/TESTING.md) · [Report feedback](https://github.com/DagerottDev/OpenMoto/issues/new/choose)

### [YouTube Playlist Sync](https://github.com/DagerottDev/Youtube_Obsidian_Sync)

Turn public YouTube playlists into searchable Obsidian notes with metadata, transcripts, and playlist indexes. Optional AI summaries; repeat syncs preserve existing video notes.

[Install from Obsidian Community Plugins](https://obsidian.md/plugins?id=youtube-playlist-sync) · [Source](https://github.com/DagerottDev/Youtube_Obsidian_Sync)

[Source](https://github.com/DagerottDev/SimulatorApiFlow) · [Usage guide](https://github.com/DagerottDev/SimulatorApiFlow/blob/main/docs/USAGE.md)
